Request Data Flow

Vue filter state → api.js (Axios) → GET /api/* ?warehouse&category&status&month → FastAPI route → in-memory filter → Pydantic validate → JSON response → reactive refs → computed → render

Four global filters (Time Period, Warehouse, Category, Order Status) are passed as query parameters on every request. Raw responses land in Vue ref() stores; all derived metrics are computed() so the UI re-renders automatically when filters change.
